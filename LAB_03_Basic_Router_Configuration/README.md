# Basic Router Configurations Lab

A Cisco Packet Tracer lab focused on learning and practicing the fundamental configuration of Cisco routers. This project covers the initial setup tasks required to prepare a router for deployment, including hostname configuration, interface configuration, IP addressing.

## 📌 Objectives

- Configure a Cisco router from its default state.
- Assign a hostname to the router.
- Configure IPv4 addresses on router interfaces.
- Save and verify router configurations.
- Test connectivity between connected devices.

## 🚀 Lab Tasks

- Configure the router hostname.
- Configure interface IP addresses.
- Bring interfaces online.
- Configure console access.
- Configure privileged mode password.
- Configure remote access (VTY).
- Encrypt passwords.
- Configure a login banner.
- Save the configuration to NVRAM.
- Verify the configuration using Cisco IOS show commands.
- Test end-to-end connectivity.
